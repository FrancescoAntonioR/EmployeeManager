# EmployeeManager

**EmployeeManager** è un'applicazione web sviluppata con React, JavaScript e CSS che permette di visualizzare e modificare le informazioni dei dipendenti attraverso un'interfaccia semplice e intuitiva.

Il progetto nasce come esercitazione pratica per consolidare le conoscenze di React, con particolare attenzione alla gestione dello stato, alla comunicazione tra componenti e alla realizzazione di form controllati.

## Funzionalità

- **Visualizzazione dei dipendenti:** elenco con nome, ruolo e stipendio.
- **Modifica dei dati:** possibilità di aggiornare le informazioni di un dipendente.
- **Validazione dei form:** controllo dei campi obbligatori e verifica della validità dello stipendio.
- **Annullamento delle modifiche:** possibilità di uscire dalla modalità di modifica senza salvare.
- **Design responsive:** interfaccia adattabile a smartphone, tablet e desktop.

Nella versione 1.0 è possibile modificare un solo dipendente alla volta.

## Tecnologie utilizzate

- **React** — Realizzazione dell'interfaccia attraverso componenti riutilizzabili.
- **JavaScript (ES6+)** — Gestione dei dati e della logica applicativa.
- **CSS3** — Stile dell'interfaccia e layout responsive.
- **Vite** — Ambiente di sviluppo e build dell'applicazione.

## Competenze approfondite

- Gestione dello stato con `useState`.
- Comunicazione tra componenti attraverso le props.
- Rendering dinamico di liste con `map()`.
- Ricerca e aggiornamento di oggetti negli array con `find()` e `map()`.
- Aggiornamento immutabile dello stato.
- Gestione di input controllati.
- Rendering condizionale.
- Validazione dei dati inseriti dall'utente.
- Realizzazione di layout responsive con Flexbox e media query CSS.

## Versioni

### v1.0.0 — Prima versione

La versione iniziale introduce le funzionalità fondamentali:

- Visualizzazione dell'elenco dei dipendenti.
- Modifica individuale dei dati.
- Validazione dei campi.
- Salvataggio e annullamento delle modifiche.
- Interfaccia responsive.

La versione successiva amplierà le funzionalità dell'applicazione introducendo:

- Modifica simultanea di più dipendenti.
- Aggiunta di nuovi dipendenti.
- Eliminazione con richiesta di conferma.
- Validazione indipendente dei form.
- Messaggi di conferma delle operazioni.
- Miglioramenti dell'accessibilità e della navigazione da tastiera.
